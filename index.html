How to get your live data
  1. Open strods.uk/overview while signed in.
  2. Open DevTools (⌥⌘I), go to the Network tab and type land-grab in the filter. Reload if nothing shows.
  3. Right-click the request, then Copy → Copy response.
  4. Paste it above. It stays in this browser and is never uploaded.
