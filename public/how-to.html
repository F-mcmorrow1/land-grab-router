Getting your land-grab data

The planner needs the same data the strods.uk map is drawn from. Your browser already downloads it whenever you open the overview page; this guide shows how to find that download in the developer tools and copy it across. It takes about a minute once you've done it before.

Before you start

  • A desktop browser. Chrome, Edge, Brave, Arc, Firefox or Safari on a Mac or PC. Phone browsers don't have developer tools; see using a phone for the workaround.
  • You're signed in to strods.uk, on Worst Pace Scenario. The data comes from your account, so a signed-out browser gets nothing, and the planner only opens for data from a Worst Pace Scenario member.
  • The land grab is running. The map ("The map who holds what") only appears on the overview page while the land-grab challenge is live. If you can't see the map there, there's no data to copy.

What you're looking for

When the map section of strods.uk/overview loads, the page fetches one request:

GET https://api.strods.uk/clubs/{your club id}/land-grab

The reply is JSON: every team, every hexagon crossed this week, and every activity that crossed them. The page asks for it again every five minutes while it stays open. The Network tab in the developer tools lists every request a page makes, so the job is to find that one and copy its reply.

Step by step

  1. Open the overview page. Go to strods.uk/overview and scroll down until you see the map.
  2. Open the developer tools. Press ⌥ ⌘ I on a Mac, or Ctrl Shift I (or F12) on Windows. You can also right-click anywhere on the page and choose Inspect. A panel opens, docked to the side or bottom of the window.
  3. Go to the Network tab. It's in the row of tabs along the top of the panel. If the panel is narrow it may be tucked behind a » button.
  4. Reload the page. Press ⌘ R (Mac) or Ctrl R (Windows) with the developer tools still open. They only record requests made while they're open, so anything from before is missing. Scroll down to the map again so it loads.
  5. Filter to the request. Click the Filter box at the top of the Network tab and type land-grab. Clicking Fetch/XHR next to it hides images and scripts too. You should be left with one row (or a few, if the page has refreshed itself).
  6. Check it's the one. Click the row. The Headers tab should show a Request URL ending in /land-grab and Status Code 200. The Preview tab shows the reply as a tree you can expand: teams, cells, activities and so on.
  7. Copy the response. Right-click the row in the list and choose Copy → Copy response. The whole reply is now on your clipboard. (Not Copy as cURL or Copy URL; those copy the request, not the data.)
  8. Paste it into the planner. See loading it below.

Check you've got the right thing

What you copied should start with {"teams":[ and be a few tens of kilobytes or more. The planner only needs these fields; anything else is ignored.

FieldWhat it is
teamsEach team's name and colour.
cellsEvery hexagon crossed this week, as H3 IDs like 881f1d4887fffff.
activitiesEach run, walk or ride: the athlete's first name, their team, when it started (minutes since Monday 00:00) and which cells it crossed, in order.
regionsThe named areas the site's map jumps between, with their bounds.
your_team, your_regionWhich team and area are yours. The planner checks your_team is Worst Pace Scenario and always plans for us.
todayDay of the week, 0 for Monday.

The planner doesn't take the site's word for who holds what: it replays every crossing of the week with the game's rules (most crossings wins, ties go to whoever got there first), so its map should match the site's exactly.

Load it into the planner

  1. Open the planner at the Land Grab Router home page.
  2. Paste. Under Game data, open Paste JSON, paste into the box (⌘ V / Ctrl V) and click Load pasted data.
  3. Check the status line. It should read something like 4 teams · 312 hexagons held · 85 activities this week, the standings appear, and the map jumps to your area.
  4. Check it says "Planning for Worst Pace Scenario" under the status line. The planner always plans for us.
Prefer a file? Paste what you copied into any plain-text editor and save it as land-grab.json, then use Load JSON file. That's also the way to get data onto a phone.

Shortcuts for next time

Once you know your club's ID you can skip the filtering. It's the number in the request's URL: in the Network tab, right-click the request and choose Copy → Copy URL, or read it from the Headers tab.

Open the data directly

While signed in to strods.uk, open this address in a new tab (with your club ID in place of CLUB_ID):

https://api.strods.uk/clubs/CLUB_ID/land-grab

If your browser sends your strods.uk login along (most do for a link opened like this), you'll see the raw JSON. Select all, copy, paste into the planner. Bookmark it to make next time two clicks. If you see an error such as "Unauthorized" instead, use the Network tab method.

Copy it from the Console

On a strods.uk tab, open the developer tools, switch to the Console tab and run:

copy(await (await fetch("https://api.strods.uk/clubs/CLUB_ID/land-grab", { credentials: "include" })).text())

Nothing visible happens, but the data is now on your clipboard. copy() works in Chrome, Edge and Firefox consoles.

A word on pasting into the Console. Chrome may ask you to type allow pasting first. That's a guard against scams that trick people into running code that steals their account. This line only reads the same land-grab data the page already loads, but as a rule, never paste Console code you don't understand, and never from someone who's asking you to.

Using the planner on a phone

Phone browsers have no Network tab, so fetch the data on a computer and send it over:

  1. Copy the data on your computer using any method above.
  2. Save it as a file: paste into a text editor and save as land-grab.json.
  3. Send it to your phone by AirDrop, email, Messages or a cloud drive.
  4. Open the planner on your phone, tap Load JSON file and pick the file.

The phone keeps it until you load something else, so you only need to do this when you want fresher standings. The opened-directly address from the shortcuts also works in a phone browser that's signed in to strods.uk; long-press to select all and copy.

Keeping it fresh

  • It's a snapshot. The planner sees the map as it was when you copied it. If others have been out since, copy it again before planning a run.
  • The site refreshes every five minutes. With the overview page open, a new land-grab request appears in the Network tab every five minutes. The newest is at the bottom of the list.
  • The week resets on Monday. Hexagons are claimed afresh each week, so last week's data plans last week's game.

Troubleshooting

No land-grab request appears
  • Reload with the developer tools open; they don't record requests from before they were opened.
  • Scroll down to the map. It loads only when the page reaches it.
  • Check the map is on the page at all. It's only shown while the land-grab challenge is live.
  • Check the filter row: clear any other filters, untick Invert, and click All to show every request type.
  • Make sure you're on strods.uk/overview, not another page of the site.
The status is 401 or 403, or the reply says unauthorised

You're signed out, or your session expired. Sign in on strods.uk, reload the overview page and try again.

"Copy response" is missing or copies nothing
  • Wait until the request has finished (the Status column shows 200, not "pending").
  • Tick Disable cache at the top of the Network tab and reload, so the reply is downloaded fresh.
  • Make sure you right-clicked the request in the list on the left, not something in the details pane.
  • As a fallback, open the Response tab, click into the text, select all and copy.
The planner says "That doesn't look like land-grab data"
  • You may have copied a different request (the page also loads leaderboards, teams and more). Check the URL ends in /land-grab.
  • You may have copied the request headers or a cURL command. The data starts with {"teams".
  • The paste may be cut short. Try saving it to a file and using Load JSON file instead.
My team or the standings look wrong
  • Copy fresh data: the standings are only as new as your copy.
  • If the planner's map really disagrees with the site's for the same moment, the site's rules may have changed. Please report it.

Privacy

  • What's in it. The reply includes the first names of athletes in your club, their teams, roughly where and when they were active this week, and which activities are yours. Treat it like the club's own data.
  • Where it goes. The planner runs entirely in your browser. Data you paste or load is kept in this browser's local storage for this site and never uploaded anywhere. Street maps come from OpenFreeMap; only the map area is requested, not your game data.
  • Removing it. Loading other data replaces it. To remove it altogether, clear this site's data in your browser's settings.
  • Sharing. Don't post the JSON publicly or commit it to a public repository. Share routes (the GPX) instead.
